# Boehm

**Performance testing automation via MCP — a unified control plane for AI-driven load testing.**

Named after [Barry Boehm](https://en.wikipedia.org/wiki/Barry_Boehm), known for the COCOMO cost estimation model and spiral model of software development.

## Vision

Boehm is a Model Context Protocol (MCP) server that gives AI coding agents a unified interface to run, compare, and analyze performance tests across multiple tools — Tulip, k6, JMeter, Gatling, and more. It turns performance testing into a first-class CI feedback loop that agents can drive autonomously.

### What Boehm will do

- **Run tests** across any supported tool through a single MCP interface
- **Compare results** against tagged baselines and detect regressions
- **Integrate with git** — check PRs, bisect regressions to individual commits, and gate CI
- **Analyze deeply** — statistical distribution comparison, trend detection, anomaly flagging
- **Report via skills** — Markdown + Mermaid reports generated by opencode skill files that agents load
- **Compare across tools** — validate that Tulip, k6, and Gatling agree on the same endpoint

### Phases

| Phase | What |
|---|---|
| 1 | MCP server scaffold + Tulip adapter |
| 2 | Baseline store & comparison tools |
| 3 | Evals / test framework for Boehm itself |
| 4 | More adapters (k6, JMeter) |
| 5 | Agent integration patterns & docs |
| 6 | Git PR integration & commit-level bisect |
| 7 | Advanced statistical analysis |
