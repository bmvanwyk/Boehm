# Boehm

**Performance Testing AI Engineer — MCP, agents, skills, and analysis for understanding and improving system performance.**

Named after [Barry Boehm](https://en.wikipedia.org/wiki/Barry_Boehm), known for the COCOMO cost estimation model and spiral model of software development.

## Vision

Boehm is an AI engineer specialized in performance testing. It combines:

- **MCP server** — the instruments and lab equipment (run tests, compare baselines, query results)
- **Skills** — engineering methodology and domain expertise (how to test, what to look for, how to interpret)
- **History tracking & baselines** — the lab notebook (every result preserved, baseline tagged for comparison)
- **Statistical analysis** — deep investigation beyond surface metrics (distribution comparison, trend detection, anomaly flagging)
- **Git integration** — the ability to investigate PRs, bisect regressions to individual commits, and answer "what change caused this?"

The agent (Claude Code, Cline, etc.) becomes the engineer. Boehm is its toolkit, memory, and expertise — working together as a performance testing specialist that can design experiments, run them, analyze results, and track down the source of regressions.

### What Boehm will do

- **Run performance tests** across Tulip, k6, JMeter, Gatling, and more through a single MCP interface
- **Keep history** — every run preserved, any run can be a baseline, compare current vs baseline
- **Investigate PRs** — check out branches, run tests, compare results, blame individual commits for regressions
- **Analyze deeply** — statistical distribution comparison, trend detection, anomaly flagging, resource correlation
- **Report clearly** — Markdown + Mermaid reports generated by skills that agents load and use
- **Cross-validate tools** — confirm Tulip, k6, and Gatling agree on the same endpoint

### Phases

| Phase | What |
